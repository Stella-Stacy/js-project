Foodie
A simple food delivery website built with HTML, CSS and JavaScript.

JavaScript

The main JavaScript functionality is the shopping cart

Some of the new JavaScript concepts used are:

-querySelector() and querySelectorAll() – used to select elements from the HTML.
-addEventListener() – makes buttons respond to actions like clicks
-forEach() – goes through multiple buttons or cart items
-closest() – finds the food card connected to the clicked Add button
-find() – checks if a food is already in the cart.
-push() – adds a new food to the cart array
-createElement() – creates HTML elements using JavaScript
-appendChild() – adds the created elements to the page
-textContent – gets or changes text on the page
-innerHTML – adds HTML content dynamically
-parseFloat() – converts the food price from text into a number
-classList.add() – adds CSS classes to elements

_How It Works_

When the user clicks Add, JavaScript gets the food's name, price and image and stores them in a cart array

If the food is already there, its quantity increases instead of creating another item

The cart count is then updated, and clicking the cart button creates the cart panel and displays the selected foods.

The project also has buttons prepared for features like favorites, search, navigation and subscription.
